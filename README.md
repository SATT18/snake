# Snake

Классическая змейка на TypeScript, упакованная в нативное приложение для Windows через Electron.

## Управление

- Стрелки / WASD — движение
- Пробел / P / Esc — пауза
- Enter — новая игра

## Запуск

```bash
npm install
npm start
```

## Сборка .exe

```bash
npm run dist
```

Готовые файлы появятся в `release/`: установщик `Snake Setup <версия>.exe` и portable `Snake <версия>.exe`.
