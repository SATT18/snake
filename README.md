# Змейка 3D

Змейка на TypeScript с яркой мультяшной 3D-графикой (Three.js: PBR-материалы, мягкие тени, ambient occlusion, HDR bloom, частицы). Поле — парящий остров над океаном, камера от третьего лица: классическая (без вращения) или за спиной змейки.

- **Играть в браузере:** https://satt18.github.io/snake/
- **Скачать для Windows и macOS:** [Releases](https://github.com/SATT18/snake/releases/latest)

## Уровни

Пять уровней, каждый открывается после прохождения предыдущего. Цель — собрать нужное число монет; за время даются от одной до трёх звёзд. Лучшие результаты видны в меню, после последнего уровня идут титры.

1. **Зелёная долина** — ровное поле, 8 монет, день
2. **Каменный сад** — валуны, 10 монет, день
3. **Живой лабиринт** — коридоры из изгородей, 12 монет, после полудня
4. **Мельница на закате** — крючья из кустов и камни, 14 монет, закат
5. **Лунный лабиринт** — лабиринт под луной, 16 монет, ночь

Перед стеной змейка один шаг ждёт и мигает — можно успеть повернуть. Монеты не появляются вплотную к стенам и препятствиям.

## Управление

- Классическая камера (по умолчанию): стрелки / WASD — направление на поле
- Камера за спиной: ← → / A D — повернуть налево / направо относительно курса, ↑ / W — старт
- Пробел / P — пауза, Esc — пауза или выход в меню
- В меню: ← → — выбор уровня, Enter — играть, C — режим камеры
- На телефоне: тап — старт, свайп — поворот

## Установка

- **Windows:** `Snake-Setup-<версия>.exe` — установщик, `Snake-<версия>-portable.exe` — без установки. Приложение не подписано: если SmartScreen предупредит, нажмите «Подробнее» → «Выполнить в любом случае».
- **macOS:** `Snake-<версия>-mac-arm64.dmg` для Apple Silicon, `...-mac-x64.dmg` для Intel. Приложение не подписано и не нотаризовано: при первом запуске откройте его через правый клик → «Открыть». Если macOS пишет, что приложение повреждено, выполните `xattr -cr /Applications/Snake.app`.

## Разработка

```bash
npm install
npm start          # собрать и запустить в Electron
npm run dist       # установщик и portable-версия для Windows → release/
npm run dist:mac   # .dmg для macOS (собирается только на Mac)
npm run icon       # пересобрать иконки из build/icon.svg
```

Веб-версия — это `dist/renderer` после `npm run build`, её можно открыть любым статическим сервером.

## Автоматизация (GitHub Actions)

- `.github/workflows/pages.yml` — при каждом push в `main` собирает веб-версию и публикует на GitHub Pages.
- `.github/workflows/release.yml` — при публикации релиза собирает версии для Windows и macOS на соответствующих раннерах и прикладывает их к релизу.
